# datasets/ — 数据集区（真实数据）

> Foundry 语义对照：本目录 = 数据集（Dataset）区，由"数据接入层"（Claude 会话调金融技能）产出，
> 引擎 Funnel 从这里物化对象，引擎自身不涉网。

## 如何更新行情

两条路（都不需要改引擎代码）：

1. **对话内更新**：在 Claude 会话里说"刷新科创板50 行情"，由 AI 调数据源拉取并按下方字段
   规则落成 CSV——本仓库当前数据就是这么来的；
2. **自写取数脚本**：任何数据源都行，产出符合下方"文件与字段"结构的 CSV 即可。

数据源密钥走环境变量（永不入库，模板见根目录 `.env.example`）：
同花顺问财 OpenAPI 用 `IWENCAI_BASE_URL` / `IWENCAI_API_KEY`；
东方财富系渠道用 `EASTMONEY_BASE_URL` / `EASTMONEY_API_KEY`。

CSV 更新后执行 `pnpm cli materialize`（或页面上的「⟳ 重新物化数据集」）：底表重建、
脏值出报告、你经 Action 做的修改由编辑账本重放保留。

## 数据来源与日期

- 拉取日期：**2026-08-04**（收盘后）
- 来源：**同花顺问财**（https://www.iwencai.com/unifiedwap/chat）OpenAPI，经 `hithink-astock-selector` 技能
- 查询语句：
  1. `科创50成份股的最新价、总市值、市盈率、市净率、申万一级行业`（成分清单 + 总市值）
  2. `科创50成份股的市盈率(TTM)、所属申万一级行业`（最新价/PE(TTM)/PB/行业）

## 文件与字段

| 文件 | 内容 | 说明 |
|---|---|---|
| `stocks.csv` | 科创50 全部 50 只成分股 | code(6位代码)/name/industryCode/latestPrice/marketCapYi(亿)/pe(TTM)/pb |
| `industries.csv` | 申万一级行业 10 个 | code(sw_拼音)/name；覆盖成分股全部行业 |
| `portfolios.csv` | 种子模拟组合 1 个 | cash = initialCash − Σ(数量×成本价)，自洽 |
| `positions.csv` | 种子持仓 2 笔 | 中芯国际 500股@115.04、金山办公 300股@260.73 |

## 数据准备规则（透明记录，不静默）

1. **亏损公司 PE 置空**：数据源对未盈利企业返回负 PE(TTM)（数学可算、估值语义无效——行情软件惯例显示"亏损"）。
   落盘时负 PE 置空（下表 14 只），保留其余字段；引擎 Funnel 将其如实置空并计入 nulled 报告。
2. 行业代码 `sw_<拼音>` 为本项目自定编码（申万官方数字码在学习场景无必要）。
3. 其余字段一律原样保留，不做四舍五入之外的加工（市值换算为亿，保留 2 位）。
